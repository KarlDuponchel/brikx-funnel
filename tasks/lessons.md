# Leçons

## Textes collés par l'utilisateur
- Ne pas recopier telles quelles les guillemets « » d'un texte collé : ils servent souvent à délimiter les phrases, pas à les afficher. En cas de doute, demander.
- Apostrophes dans le JSX : utiliser `&apos;` (règle `react/no-unescaped-entities`). Dans une chaîne JS (ex. `lib/constants.ts`), garder `'`, car `&apos;` s'y afficherait tel quel.
